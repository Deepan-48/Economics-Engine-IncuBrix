How Versioning Works

Every save creates a new version. The previous version is kept but deactivated. Rollback restores the previous version instantly.

Only the active version is used for cost estimation.

Policy Thresholds

Routes where estimated_high_cost >= this % of cap get a warning status. Default: 0.85 (85%)
Async route gets recommended flag when it saves more than this % vs sync. Default: 0.15 (15%)
